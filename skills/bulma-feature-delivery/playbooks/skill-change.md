# Skill change

Use existing authoring conventions. `structural-checks` records executed checks
for frontmatter, references, distribution and any changed helpers. A test should
reject a real broken variant and accept valid behavior, not assert prose wording.

For changes to routing, autonomy, retries, proof or completion, run a targeted
behavior evaluation before marking `behavior-evaluation` pass. Use natural tasks,
isolated starting state and the existing [experiment protocol](../../bulma-bus/EXPERIMENTS.md).
Hold expectations out of candidate context. A judge sees sanitized labels, not
model names. Inspect actual tool traces and artifacts, not claims about compliance.

Typography or wording with no decision change may skip behavioral evaluation with
that reason. Otherwise, an unavailable host or budget leaves evaluation pending
and is reported as unverified. Do not disguise missing evaluation as a subjective
edit. A small pilot tests a contract; it does not establish productivity gains.
Keep paid evaluations explicit and bounded; do not launch a full corpus by default.
