# Node: learn

**Verb:** turn verified feedback into prevention
**Capability:** write runtime assessments, scoped project memory and issue
drafts. Publish issues only under the authorization rules below.

Apply [FEEDBACK.md](../../bulma-bus/FEEDBACK.md) to verified dispositions and
existing prove/QA evidence. Include confirmed bot findings as well as human
findings. Do not treat invocation, CHANGES_REQUESTED, or missing evidence as a
confirmed escape. Skip-only runs record `no_action` and the reason unless a
confirmed defect remains, such as a valid out-of-scope finding.

Set `status=learning`. Record `feedback_status`, `feedback_paths` and
`feedback_tasks` in STATE. Reconcile existing source/pattern records before
writing, so resume does not create another lesson or issue. Follow the shared
contract for issue eligibility, destination and publication. Default to drafts.
No paid classifier or extra review worker is needed.

Then **report**. If collection or writing fails, retain a pending reason and
continue to report. A blocked product fix can still supply an assessment, but
must retain its failed or pending proof status.
