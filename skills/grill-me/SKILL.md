---
name: grill-me
category: lib
description: Interview the user to stress-test a plan or design when they request a design interview or grill-me session.
---

Explore the plan's consequential decisions until the requested design is actionable.
Use this for a requested interview. Routine Bulma delivery uses
[bounded discovery](../bulma-feature-delivery/GRILL.md) instead.

Read supplied context and relevant code before asking for recoverable facts.
Challenge assumptions with concrete scenarios. Explain what each answer changes
and give a recommendation when useful; confidence does not establish user intent.

Ask dependent questions one at a time. Bundle up to three independent questions
when this saves a round trip. Preserve answered decisions. Stop when the requested
scope, constraints and acceptance criteria are actionable or the user ends the
interview; do not exhaust branches with no consequence for the plan.
